# CBFESTA

학교 축제를 탐험하고 팀 미션을 함께 완성하는 반응형 페스티벌 경험입니다.

## Start

```bash
npm install
npm run dev
```

## Visual system

- Original CBFESTA color, symbol, spatial layout, and procedural 3D team artifact
- Six intentional glass material levels defined as shared CSS tokens
- Tossface for licensed expressive graphics and Lucide for functional icons
- Motion hierarchy with reduced-motion support
- Mobile, tablet, laptop, and desktop recomposition
